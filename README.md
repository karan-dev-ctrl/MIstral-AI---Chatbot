💬 Mistral AI Chatbot App

An intelligent, AI-powered Chatbot Web Application built with Next.js 14, Mistral AI Open API, Tailwind CSS, shadcn/ui, and Clerk authentication.
This project delivers a secure, responsive, and visually polished chat experience — showcasing modern full-stack development, AI integration, and scalable frontend architecture.

🔧 Tech Stack

Frontend: Next.js 14, React 18, TypeScript, Tailwind CSS, shadcn/ui
AI Integration: Mistral AI Open API
Authentication: Clerk (Email, OAuth, JWT)
Styling & UI: Tailwind CSS, shadcn/ui, Lucide Icons

🌟 Key Features

🤖 Mistral AI Integration: Harnesses Mistral’s Open API for natural, context-aware conversations.
🔐 Secure Authentication: Powered by Clerk for sign-in, session management, and role-based access.
💬 Real-Time Chat Interface: Sleek, responsive UI built with shadcn/ui and Tailwind CSS.
